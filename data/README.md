# Data

## Source

Kaggle **Wound Classification Dataset** by Ibrahim Fateen: <https://www.kaggle.com/datasets/ibrahimfateen/wound-classification>.
It has 10 class folders and 2,940 images; the notebook deletes `Normal` and keeps nine wound classes. The images are **not redistributed here**; check the dataset's licence on Kaggle before sharing any of them.

| Class | Images in the Kaggle archive |
|---|---|
| Abrasions | 164 |
| Bruises | 242 |
| Burns | 134 |
| Cut | 100 |
| Diabetic Wounds | 462 |
| Laseration (sic) | 122 |
| Normal (dropped) | 200 |
| Pressure Wounds | 602 |
| Surgical Wounds | 420 |
| Venous Wounds | 494 |

## What the notebook builds from it

| Stage | Folder (Drive) | Content |
|---|---|---|
| 1 | `RAC/Wound_dataset` | the Kaggle images, `Normal` removed |
| 2 | `RAC/Data` | 100 random images per class (seed 54), 900 in total |
| 3 | `RAC/Data224` | augmented, 224x224, 1,000 per class, 9,000 in total |
| 4 | `RAC/Datat/{train,val,test}` | 80/10/10 split of stage 3 (seed 69): 800 / 100 / 100 per class |
| 5 | `RAC/Kfold/fold_1..5` | optional 5-fold split of stage 3 (commented out in the notebook) |

Stages 3 to 5 are regenerated by the notebook, so they are not stored here.

## Rebuilding the paper's 900-image subset

[`subset_manifest.csv`](subset_manifest.csv) lists the exact files of stage 2 (class, filename, bytes, SHA-256). With the Kaggle archive unzipped:

```
python scripts/rebuild_subset.py <unzipped-kaggle-folder> <output-folder>
```

The script copies the 900 files and checks every checksum. This is the subset behind the paper's numbers, so using it removes the randomness of the selection step (the augmentation and the split are still random unless you fix their seeds).
